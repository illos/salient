# Draw Steel table-command rules inventory

Research status: source-grounded design input, 2026-09-11. This report proposes conceptual operation and argument families; it does not select command spelling, implementation schemas, pending-action policies, or new product scope.

Authoritative corpus: `vendor/steel-compendium`, pinned commit **`fb83a789da8f0327a389c277a0c790b1648d5810`**, verified locally. Evidence below comes from the core **Heroes** (`mcdm.heroes.v1`) and **Monsters** (`mcdm.monsters.v1`) books. Numbered citations resolve to the source inventory at the end. The unified Markdown is an extraction, not an independent source from the book-specific Markdown/clean text. No vendor or application code was changed.

## 1. Findings and scope

A command system needs more than “actor, ability, target, roll.” The same invocation can require selected targets, a geometric area, targets discovered during movement, a different creature making a granted action, per-target modifiers, a post-roll choice, a response before damage or movement completes, and effects maintained across later events. A test can instead require a Director-defined task and difficulty, assistance, several independent rollers, comparison against opponents, or interpretation of a narrative consequence. A saving throw is a distinct **d10 roll succeeding on 6+ to end a save-ends effect**, not a characteristic test or an ability-defense roll. Potencies usually compare a characteristic against a threshold without rolling.[1–15]

The appropriate research unit is a **mechanically distinct interaction**, not one bespoke command per printed ability. This inventory covers the general rules, basic actions, all nine core classes' resource models, and representative exceptions through level 10. It also identifies extension needs from core items, monsters, terrain, respite, and deferred structured activities. It is not an exhaustive ability implementation audit: proving every ability requires later bounded source review and execution coverage.

Scope boundaries from the project remain controlling:

- **v0.01:** narrow level-one devil Fury journey; basic combat, readable used content, manual adjustments, history, and shared headless operations. This inventory does not make complete command-family automation a prototype gate.
- **Fuller V1:** nine core classes through level 10, FreePlay, combat and dedicated respite. Detailed respite delivery remains unresolved. Inventory is deferred beyond v0.01. Special turns and broader feature automation are fuller-product work.
- **Beyond V1 / deferred extensions:** playable retainers and friendly monsters; montage and negotiation flows; downtime projects and nested activities. Core material can remain readable while a playable subsystem is deferred. Core features that summon allies must retain their source references and report the unsupported portion rather than silently importing a complete ally subsystem.
- **Excluded:** supplemental Summoner, Beastheart and associated supplemental mechanics. Their appearance in the unified corpus does not make them core. A core Fury's stormwight transformation is still core Fury content.

## 2. Conceptual arguments: what must be representable

These are recommendations derived from the rules, not approved wire schemas. **R** means required for a faithful resolution of that interaction; it may come from persisted state or an earlier response rather than the initial typed command. **O** means genuinely optional choice. **D** means normally derived from authoritative actor/content/state. **U** means a fact that can be unknown in a map-independent client; missing is not false. A field can be R/U when required to decide a rule but unavailable until supplied. Cards are discussed separately below.

### 2.1 Selection is separate from effect outcome

Rules facts:

1. An ability's creature targets normally exclude the actor unless it also targets self or explicitly permits self. Object targeting has its own immunities and effect restrictions; objects automatically obtain tier 1 if forced to make a test. “Each” area wording includes every eligible target; numeric target limits permit fewer targets.[12]
2. An ability with multiple targets normally makes one power roll. Edges/banes against individual targets can yield different totals and tiers. Choosing melee versus ranged changes the applicable keyword rather than giving both simultaneously.[9][13]
3. Unless the ability says otherwise, damage is dealt to **all targets before tier effects**. Multiple effects resolve in printed order. An effect on the actor or Director occurs once, even if damage hit multiple targets; if tiers differ, the actor chooses which rolled-effect tier applies to that actor/Director effect.[10]
4. A potency is a strict comparison: the effect applies only when the target characteristic is **less than** potency. A spend entirely dependent on a resisted potency is not paid; a spend that also has an automatic effect is still paid.[14]
5. Surge damage and potency increases have explicit allocations. Up to three surges add rolled damage to one target; two surges raise one target's potency by one, and more pairs can raise potency against other targets. This is not a global “+surges” knob.[24]

Recommendation: record shared dice once, with separate target-specific calculations and effects; preserve choices made after those calculations. Do not collapse “chosen,” “eligible,” “affected,” “resisted,” and “awaiting facts” into one targets list. The companion [targeting case study](table-command-targeting-cases.md) develops representative ability workflows.

### 4.1 Source timing versus the table interaction window

The current table policy keeps an unused detected opportunity on creature X's action active until X's turn ends, with no wall-clock countdown. That is an **app window convention**. The rules say use a triggered action when its trigger occurs; individual abilities can intervene before a consequence completes. Lines of Force says the target **would be force moved**; Grab/Escape Grab's tier-two free strike happens before the status transition.[11][17][39][P1]

Recommendation: represent the triggering event and before/after relationship independently of the card's visible lifetime. A remaining visible card does not prove that using it late follows the source. Whether the app waits, applies provisional effects, records a correction, or allows a warned late response remains a product/engineering decision. No universal “all triggers valid until end of turn,” mandatory all-player pass barrier, or automatic rollback is established here.

The critical-hit entry calls its opportunity-attack example a “triggered action”; the dedicated Opportunity Attacks entry specifies **free triggered action**. Keep the specific rule's allowance classification and the critical-hit example's inner-main-action eligibility, rather than treating the wording as an additional ordinary-trigger cost.[11][20]

### 5.2 Other core character options

The source-of-feature boundary must also admit ancestry traits, perks, kits and titles; an operation is not necessarily a class ability. Representative direct checks add these shapes:[50]

- Human Determination ends selected conditions as a maneuver; Perseverance changes the slowed speed rule, and Can't Take Hold modifies source-keyword-specific terrain/forced movement. Devil Silver Tongue supplies a negotiation-specific edge. These are source contributions to actions or rule interpretation, not new unrelated global commands.
- Pardon My Friend changes **who rolls** a replacement test and caps use across every creature possessing the perk. Expert Artisan chooses between two complete rolls. Keep rolling, replacing, selecting dice and selecting a final roll distinguishable.
- Heist Hero's Sneakers permits assistance within a group test, overriding the general restriction. Its Timely Distraction reroll has a **per-target one-hour** reuse restriction. Generic “used this ability” booleans cannot cover that key.
- Blood Magic can trade irreducible damage for an area change, requiring a **chosen dimension** for a line, or add a later damage instance with a defeat-dependent refund. This combines alternate payment, geometry choice and a conditional refund.
- Gum Up the Works reacts to a trap activating, moves the actor, and prevents activation if adjacency is achieved; ongoing prevention depends on staying adjacent and can be broken by failed disarm. It is another source-specific interruption, beyond class reactions.
- Fleet Admiral's weather option needs an uninterrupted ten-minute activity, daily use cap, selected weather, mobile five-mile area and six-hour duration. It confirms fictional time and narrative environment changes outside combat.

These examples do not constitute exhaustive ancestry, perk, kit, title or complication coverage. Their remaining source-specific payloads should fit the argument/effect families above or be reported as unsupported when encountered. Character-build choices themselves belong to the character system, rather than being inferred as table gameplay commands.
